## Data Analytics & Machine Learning Projects

## 📌 Overview

This repository contains a collection of data analytics and machine learning mini-projects, covering data preprocessing, exploratory data analysis (EDA), predictive modeling, model evaluation, and data visualization. Each project focuses on applying data-driven techniques to solve practical problems and demonstrate analytical and machine learning skills.

---

## 🚀 Projects

### 1. Customer Churn Prediction

**Objective:**
Predict whether a telecom customer is likely to discontinue the service based on customer demographics, account details, and service usage.

**Key Highlights:**

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Logistic Regression, Random Forest & XGBoost Models
* Model Evaluation
* Streamlit Dashboard for Churn Prediction

---

### 2. Credit Risk Modeling

**Objective:**
Predict whether a loan application is likely to be approved or rejected using customer financial and personal information.

**Key Highlights:**

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* SMOTE for Class Imbalance Handling
* Logistic Regression, Decision Tree & Random Forest Models
* Explainable AI using SHAP/LIME
* Streamlit Dashboard for Loan Prediction
